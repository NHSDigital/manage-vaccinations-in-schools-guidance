> [!NOTE]
> This guidance is for teams taking part in the clinics pilot. If your team is not taking part, use the [existing guidance for clinics](/guide/community-clinics/). We're continuing to improve these features during the pilot, so some screenshots and instructions may not match what you see in Mavis.

Before you create a session, the Mavis team needs to set up your team’s clinic locations. Contact england.mavis@nhs.net if you have questions about this.

Once your locations are set up:

1. From the Mavis dashboard, go to **Sessions**.
2. Select **Add a new session**.
3. Select **Clinic session** then **Continue**.
4. Select the vaccination programmes then **Continue**.
5. Enter the clinic location. When you start typing the clinic’s name or area, you will see options to select. Then **Continue**.
6. Enter the session date.

## Vaccination periods

Next, you need to create a vaccination period for the session. Enter the start and end time for the vaccination period.  

Create more than 1 vaccination period if you want to:

- include breaks in a clinic session (for example, create a vaccination period before lunch and another one after lunch)
- vary the number of vaccinators over the session
- To create more than 1 vaccination period, select **Add another period**.

![Screenshot of creating session vaccination periods.](/assets/images/creating-clinic-session-vaccination-periods)

Then **Continue**.

## Number of vaccinators

Next, you need to enter how many vaccinators you have for the session.

If you’ve created multiple vaccination periods you need to:

- select whether the number of vaccinators will or will not vary
- enter the number of vaccinators (if the number of vaccinators will vary, enter the number for each vaccination period)

When the number will vary by vaccination period:

![Screenshot of when vaccinators will vary.](/assets/images/creating-clinic-session-vaccinators-will-vary.png)

When the number will not vary by vaccination period:

![Screenshot of when vaccinators will not vary.](/assets/images/creating-clinic-session-vaccinators-not-vary.png)

## Remaining steps

Next, enter how long an appointment lasts, then **Continue**. 

Check and confirm your answers. On this page, you can also change your team’s default setting for registering children’s attendance.

![Screenshot of registering attendance answer.](assets/images/creating-clinic-session-register-attendance.png)

**Continue** takes you to the session overview, where you can manage a clinic session.
